# zomato-insight-dash
A dashboard of zomato by the help of excel and power bi.
This project is an interactive Zomato Insights Dashboard built using Power BI to analyze restaurant data, customer behavior, and food ordering trends.

It provides actionable insights into restaurant performance, customer preferences, and delivery efficiency.

🎯 Objectives
Analyze customer ordering behavior
Identify top-performing restaurants
Understand ratings distribution
Evaluate delivery performance
Explore popular cuisines
📊 Key Features
🔝 Top 10 Restaurants by orders
📈 Year-wise Order Trends
⭐ Ratings Distribution
🍜 Cuisine-wise Analysis
🚚 Delivery Time Analysis
💰 Average Order Value & Discount Insights
🛠️ Tools & Technologies
Power BI
Excel / CSV Dataset
DAX (Data Analysis Expressions)
Power Query (Data Cleaning)

📈 Insights
A small number of restaurants generate the majority of orders
Certain cuisines are significantly more popular
Most ratings fall in the mid-to-high range
Delivery time varies across locations
Discounts influence order volume
🚀 How to Use
Download the .pbix or .pbit file
Open in Power BI Desktop
Load dataset if required
Explore dashboard using filters
